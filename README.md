# فالکون · پوسته‌ی فارسی — Releases

فایل‌هایی که افزونه با دکمه‌ی «به‌روزرسانی» از اینجا می‌خواند. سورس در ریپوی خصوصی `falcon-farsi` است.

| فایل | کاربرد |
|---|---|
| `version.json` | شماره‌ی نسخه‌ی هسته، یادداشت انتشار، حداقل نسخه‌ی لودر |
| `core.js` | منطق RTL، ترجمه و ارقام فارسی (در صفحه‌ی فالکون اجرا می‌شود) |
| `content.css` | تم‌ها و انیمیشن‌ها |
| `falcon-farsi.zip` | افزونه‌ی کامل برای نصب اول |

**نصب اول:** zip را باز کنید ← `chrome://extensions` ← Developer mode ← Load unpacked ← پوشه‌ی `falcon-farsi`.
از آن به بعد، هر نسخه‌ی تازه با نشان «نو» روی آیکون افزونه خبر داده می‌شود و با یک کلیک نصب می‌شود.
